# نظام إدارة طلبات سحب زيت الطهي المستخدم (UCO Pickup Management)

موقع فعلي (Next.js + TypeScript + Tailwind + Supabase) لإدارة عملية سحب زيت
الطهي المستخدم من المولّدين (مطاعم، فنادق) بواسطة مجمّعين، مع تتبّع الطلب
والكمية والسعر والعمولة — بيانات حقيقية محفوظة ومشتركة بين كل الأجهزة.

**مشروع مستقل بالكامل** — لا علاقة له بأي مشروع آخر.

## الفكرة

1. مندوب ميداني يسجّل مولّدًا جديدًا (`/register`) — النظام يصدر باركود خاص به.
2. أي مسح لهذا الباركود (`/scan/?g=<id>`) ينشئ تلقائيًا طلب سحب جديد بدون أي
   تطبيق أو تسجيل دخول من طرف المولّد.
3. المجمّع (`/collector`) يختار شركته أول مرة من نفس الجهاز، ثم يشوف الطلبات
   المعلّقة، يفلترها حسب المحافظة/الولاية، يجمّعها في مسار واحد يفتح في خرائط
   قوقل بضغطة زر، ويسجّل الكمية والسعر عند التنفيذ.
4. الإدارة (`/admin`) تشوف كل المعاملات، تضيف مجمّعين جدد، وتحسب تلقائيًا
   مستحقات كل مجمّع: عمولة ٢ ر.ع لكل طن + ضريبة قيمة مضافة ٥٪.

## الإعداد (مرة وحدة)

1. أنشئ مشروع مجاني على [supabase.com](https://supabase.com)
2. نفّذ محتوى `supabase/schema.sql` كامل من: Dashboard → SQL Editor → Run
3. انسخ **Project URL** و **anon public key** من: Project Settings → API
4. أضفهم بملف `.env.local` (انسخ من `.env.local.example`):
   ```
   NEXT_PUBLIC_SUPABASE_URL=https://xxxx.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=xxxxx
   ```

## التشغيل محليًا

```bash
npm install
npm run dev
```

## البناء والنشر (GitHub Pages)

المشروع يُصدَّر كموقع ثابت بالكامل (`output: "export"`) — لا يحتاج سيرفر.
مفاتيح Supabase (`NEXT_PUBLIC_*`) تُضمَّن وقت البناء من `.env.local`.

```bash
GITHUB_PAGES_BUILD=true npm run build
```

## قيود معروفة

- **الأمان:** لا يوجد تسجيل دخول (Zero-friction UX عمدًا) — أي حد يعرف رابط
  الموقع يقدر يقرأ/يعدّل البيانات عبر مفتاح anon العام. مقبول لمرحلة أولى،
  لكن قبل أي استخدام فيه بيانات حساسة لازم تُضاف طبقة Supabase Auth.
- إشعارات الواتساب محاكاة بصرية فقط (`WhatsAppPreview`) — لا يوجد اتصال فعلي
  بـ WhatsApp Business API بعد.
- "اختيار الشركة" لدى المجمّع محفوظ محليًا على كل جهاز (`localStorage`) وليس
  تسجيل دخول حقيقي — أي شخص على نفس الجهاز يقدر يتصرّف باسم نفس المجمّع.
